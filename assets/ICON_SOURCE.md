# Icon source

Icons are downloaded from the homarr-labs dashboard-icons collection (repository
`homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/vault.svg` | Default, and fallback in the README `<picture>` element |
| `icon-dark.svg` | `svg/vault-light.svg` | Dark mode (`prefers-color-scheme: dark`); same logo with white detail fills |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/vault.svg
- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/vault-light.svg
